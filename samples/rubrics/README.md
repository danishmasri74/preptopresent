# Sample rubrics for testing

Generated by `services/worker/scripts/make_sample_rubrics.py`. To recreate them:

```bash
cd services/worker && uv run python scripts/make_sample_rubrics.py
```

> **All content is fictional test data.** Never submit or quote these as real module rubrics.

The FYP rubric is designed to pair with `samples/decks/fyp-defence-12-slides.pdf`, so rubric-to-slide alignment (F-15) has something realistic to match.
